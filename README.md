##  Ответы на контрольные вопросы❓

1. **Чем `Console.Write()` отличается от `Console.WriteLine()`?**  
   `Console.Write()` выводит текст без перехода на новую строку, а `Console.WriteLine()` после вывода текста автоматически добавляет символ переноса строки[cite: 1].

2. **Что произойдёт, если попытаться присвоить переменной типа `int` значение `3.14`?**  
   Возникнет ошибка компиляции, так как C# — язык со статической строгой типизацией, и вещественное число (`double`) нельзя напрямую записать в целочисленную переменную (`int`) без явного приведения типов.

3. **Почему `10 / 3` в C# даёт `3`, а не `3.333...`? Как получить дробный результат?**  
   В C# деление двух целых чисел (`int / int`) производит целочисленное деление с отбрасыванием дробной части. Чтобы получить дробный результат, хотя бы один из операндов должен быть типа `double`, например: `(double)10 / 3` или `10.0 / 3`.

4. **Что означает `var` в C#? Чем он отличается от динамической типизации в Python?**  
   Ключевое слово `var` включает типизацию: компилятор сам определяет тип переменной на этапе компиляции по присваиваемому значению. В отличие от Python, переменная с `var` остаётся строго типизированной и не может изменить свой тип в процессе выполнения программы.

5. **На каких крупных проектах или в компаниях используется C# и .NET?**  
   * **Microsoft** (внутренние сервисы, Azure, Windows-приложения);  
   * **Stack Overflow** (высоконагруженная веб-платформа построена на .NET)  
   * **Unity Technologies** (C# является основным языком для разработки игр в движке Unity).
